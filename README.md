# Hyunseo.log · 자기소개 페이지

> 엘리스 AI 트랙 4기 개인 실습 · 2022.01 ~ 05 · HTML, CSS, JavaScript

Node.js 백엔드 개발자를 목표로 만든 자기소개 웹페이지입니다. About Me, Campus, Portfolio, Contact 섹션으로 구성됩니다.

## 실행

`public/index.html`을 브라우저로 열면 됩니다.

## 구성

- `public/index.html`: 페이지 구조
- `public/style.css`, `interaction.css`: 레이아웃과 애니메이션
- `public/script.js`: 메뉴 이동 등 상호작용
- `.gitlab-ci.yml`: GitLab Pages 배포 설정 (GitHub에서는 동작하지 않음)
